# Reference snapshots

These documents explain structures and techniques from an earlier project state. Their relocation did not re-audit every ID, effect, class, map count or plugin claim. Live database files, enabled plugin configuration, current FAQs and local skills take precedence.

- `database/`: older actor/class/item/equipment/skill/state/enemy/troop/common-event and switch catalogs.
- `maps/`: map JSON, tileset and structure references.
- `battle/`: animation catalogs, code examples and the action-sequence compilation.
- `plugins/`: plugin guides. An installed file or documented notetag is not proof its plugin is enabled or integrated.

For current record counts and individual maps/animations/tilesets, use the [read-only inspector](../../tools/project-inspect/README.md). For production animation work use the project’s battle-animation/graphics skills and current plugin code, rather than copying an old sequence untested. The [cleanup inventory](../../tools/root-cleanup/inventory.md) links every individual reference file.
