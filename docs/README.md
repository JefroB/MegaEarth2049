# Documentation guide

Use the current sources in this order:

1. [Story continuity decisions](story/STORY_PROGRESSION.md), together with the user’s latest direction.
2. [Current player FAQs](../GameFAQs/FAQ_01_Getting_Started.md) and [unfinished-work roadmap](../GameFAQs/ROADMAP.md).
3. Live `data/`, enabled `js/plugins.js` entries, plugin implementations, and the manifests/tests under `tools/`.
4. [Authored story material](story/README.md) and older reference documents, reconciled with the sources above.

| Folder | Contents and status |
|---|---|
|[story](story/README.md)|Current continuity decisions and both authored story sources. New content should build on them.|
|[audio](audio/SOUND_EFFECTS_AUDIT.md)|Current sound library, applied cues, missing-effect requests and playback/mix evidence.|
|[reference](reference/README.md)|Database/schema, map, animation and plugin reference snapshots. Useful explanations, but not certified current ID catalogs or evidence that installed plugins are enabled.|
|[archive](archive/README.md)|Older quest implementations, event templates, plans and development guides. Retained as history; use the FAQs and live events for current routes.|

The former root documentation index is archived with the older guides. This page and the root README replace it as current navigation. The [file inventory](../tools/root-cleanup/inventory.md) records every moved file and its classification. No story outline was discarded during sorting.
