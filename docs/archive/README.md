# Historical documentation

`quests/` preserves earlier quest analyses, implementation plans and event templates. `guides/` preserves superseded development guides and the old documentation index. Their assertions and code snippets may conflict with current quests, allocations or plugin behavior. They are sources to review, not instructions to replay against the live project.

Use [the current FAQs](../../GameFAQs/FAQ_01_Getting_Started.md), [story decisions](../story/STORY_PROGRESSION.md), [roadmap](../../GameFAQs/ROADMAP.md) and live data for current behavior. Older plans do not automatically add new roadmap commitments. Original source bytes are recoverable from the cleanup snapshot (local snapshot: `../../tools/root-cleanup/root-before.zip`).
