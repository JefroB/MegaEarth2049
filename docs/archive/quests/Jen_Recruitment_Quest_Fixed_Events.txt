# Jen Recruitment Quest Fixed Events

This document provides the complete event scripts for the Jen recruitment quest with all necessary plugin commands and switch logic properly implemented. Use these scripts as a reference when implementing or fixing the quest in the game.

## Common Event: Jen Availability Check

This common event should be set to run automatically via Parallel Process.

```
// Common Event: Jen Availability Check
Trigger: Parallel Process
Event Commands:
- Conditional Branch: Actor 1's Level ≥ 3
  - If true AND Switch 21 is OFF:
    - Set Switch 21 ON (Jen is home)
    - Show Text: "You hear rumors about a former OmniCorp specialist living in Timbuc."
  - End If
- End Branch
```

## Map015 (Timbuc Cellar) Boss Event

This event handles the boss battle and obtaining Jen's necklace.

```
// Event: Timbuc Cellar Boss
// Page 1: Boss Not Defeated
Conditions: Switch 9 OFF
Event Commands:
- Show Text: "A menacing figure guards something shiny in the corner..."
- Battle Processing: Trash Octopus (or appropriate boss)
- If Win:
  - Show Text: "You defeated the creature! You found Jen's necklace among its possessions."
  - Change Items: Add "Jen's Necklace" to inventory
  - Set Switch 9 ON (Boss Defeated)
  - Plugin Command: Quest Add 6
  - Plugin Command: Quest SetObjective 6 1 complete
  - Plugin Command: Quest SetObjective 6 2 complete
  - Show Text: "This appears to be a personal item. Perhaps you should find its owner."
- If Escape/Lose:
  - Show Text: "You retreat from the powerful creature. It continues to guard its treasure."

// Page 2: Boss Defeated
Conditions: Switch 9 ON
Event Commands:
- Show Text: "You've already defeated the creature and claimed its treasure."
```

## Switch Logic Summary

Here's a summary of the switch logic for the Jen recruitment quest:

1. **Initial State**:
   - Switch 9: OFF (Boss not defeated)
   - Switch 10: OFF (Jen not recruited)
   - Switch 21: OFF (Jen not home)

2. **Level 3 Trigger**:
   - When player reaches level 3, Switch 21 is set to ON (Jen is now home)
   - This allows the player to enter Jen's house and meet her

3. **Boss Defeat**:
   - When the boss is defeated, Switch 9 is set to ON
   - This tracks quest progression and enables the necklace return dialogue

4. **Recruitment**:
   - When the necklace is returned, Switch 10 is set to ON
   - This completes the quest and adds Jen to the party

## Plugin Command Summary

Here's a summary of the plugin commands used in the Jen recruitment quest:

1. **Quest Addition**:
   - `Quest Add 6` - Adds the Jen's Lost Necklace quest to the journal
   - Used after defeating the boss and obtaining the necklace

2. **Objective Updates**:
   - `Quest SetObjective 6 1 complete` - Marks "Defeat the boss in Timbuc Cellar" as complete
   - `Quest SetObjective 6 2 complete` - Marks "Retrieve Jen's necklace" as complete
   - `Quest SetObjective 6 3 complete` - Marks "Return the necklace to Jen" as complete
   - Used at appropriate points in the quest progression

3. **Quest Completion**:
   - `Quest Complete 6` - Marks the Jen's Lost Necklace quest as complete
   - Used after returning the necklace to Jen and recruiting her
