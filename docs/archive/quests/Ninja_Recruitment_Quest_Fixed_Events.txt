# Ninja Recruitment Quest Fixed Events

This document provides the complete event scripts for the Ninja Recruitment quest with all necessary plugin commands and switch logic properly implemented. Use these scripts as a reference when implementing or fixing the quest in the game.

## Switch Setup

- **Switch 101**: Green Ninja Defeated
- **Switch 102**: Brown Ninja Defeated
- **Switch 103**: Blue Ninja Defeated
- **Switch 104**: Pink Ninja Defeated (and Recruited)
- **Switch 105**: Ninja Quest Added to Journal

## Map005 (Church Street) Green Ninja Event

```
// Event: Green Ninja
// Page 1: Not Defeated
Conditions: Switch 101 OFF
Event Commands:
- Show Text: "A green-clad figure watches you from the shadows..."
- Show Choices: ["Approach", "Leave it alone"]
- If "Approach":
  - Show Text: "The figure reveals itself as a Green Ninja and attacks!"
  - Battle Processing: Green Ninja
  - If Win:
    - Show Text: "You defeated the Green Ninja!"
    - Set Switch 101 ON (Green Ninja Defeated)
    - Conditional Branch: Switch 105 OFF (Quest Not Added)
      - Plugin Command: Quest Add 7
      - Plugin Command: Quest SetObjective 7 1 complete
      - Set Switch 105 ON (Quest Added)
      - Show Text: "You've encountered a mysterious ninja. There may be others in the area."
    - Else:
      - Plugin Command: Quest SetObjective 7 1 complete
      - Show Text: "You've defeated the Green Ninja. There are other ninja types to find."
  - If Escape/Lose:
    - Show Text: "The Green Ninja disappears back into the shadows."
- If "Leave it alone":
  - Show Text: "You decide to leave the mysterious figure alone for now."

// Page 2: Defeated
Conditions: Switch 101 ON
Event Commands:
- Show Text: "This is where you defeated the Green Ninja."
```


## Troop Event for Pink Ninja Battle

This event should be added to the Troop tab in the database for the Pink Ninja battle.

```
// Troop Event: Pink Ninja Battle End
Trigger: Battle End
Span: Once
Conditions: None
Event Commands:
- Comment: "This event runs when the Pink Ninja battle ends"
- Conditional Branch: Turn Escaped
  - If true:
    - Comment: "Player escaped"
  - If false:
    - Conditional Branch: Turn Defeated
      - If true:
        - Comment: "Player was defeated"
      - If false:
        - Comment: "Player won the battle"
        - Set Switch 104 ON (Pink Ninja Defeated)
        - Plugin Command: Quest SetObjective 7 4 complete
        - Plugin Command: Quest Complete 7
```

## Switch Logic Summary

Here's a summary of the switch logic for the Ninja Recruitment quest:

1. **Initial State**:
   - Switch 101: OFF (Green Ninja not defeated)
   - Switch 102: OFF (Brown Ninja not defeated)
   - Switch 103: OFF (Blue Ninja not defeated)
   - Switch 104: OFF (Pink Ninja not defeated/recruited)
   - Switch 105: OFF (Quest not added to journal)

2. **Ninja Defeats**:
   - When a ninja is defeated, its corresponding switch is set to ON
   - The first ninja defeated also sets Switch 105 ON and adds the quest to the journal

3. **Pink Ninja Availability**:
   - The Pink Ninja only appears when all other ninjas are defeated
   - This is controlled by the page conditions on the Pink Ninja event

4. **Recruitment**:
   - When the Pink Ninja is defeated, Switch 104 is set to ON
   - This completes the quest and adds the Pink Ninja to the party

## Plugin Command Summary

Here's a summary of the plugin commands used in the Ninja Recruitment quest:

1. **Quest Addition**:
   - `Quest Add 7` - Adds the Ninja Recruitment quest to the journal
   - Used after defeating the first ninja (whichever one the player encounters first)

2. **Objective Updates**:
   - `Quest SetObjective 7 1 complete` - Marks "Defeat the Green Ninja" as complete
   - `Quest SetObjective 7 2 complete` - Marks "Defeat the Brown Ninja" as complete
   - `Quest SetObjective 7 3 complete` - Marks "Defeat the Blue Ninja" as complete
   - `Quest SetObjective 7 4 complete` - Marks "Defeat the Pink Ninja" as complete
   - Used when each respective ninja is defeated

3. **Quest Completion**:
   - `Quest Complete 7` - Marks the Ninja Recruitment quest as complete
   - Used after defeating the Pink Ninja and recruiting them

## Testing Instructions

To test the fixed Ninja Recruitment quest:

1. Start a new game or load a save before encountering any ninjas
2. Go to Church Street (Map005) and find the ninja events
3. Defeat the Green, Brown, and Blue Ninjas in any order
4. Verify that the quest appears in the journal after defeating the first ninja
5. Verify that each objective is marked as complete when the corresponding ninja is defeated
6. After defeating all three ninjas, find and defeat the Pink Ninja
7. Verify that the Pink Ninja joins the party and the quest is marked as complete
8. Check that Switch 104 is ON, indicating the Pink Ninja has been recruited

By following these event scripts and testing instructions, you can ensure that the Ninja Recruitment quest works correctly with both proper switch logic and quest journal integration.
